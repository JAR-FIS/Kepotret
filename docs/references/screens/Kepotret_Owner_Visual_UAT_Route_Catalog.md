# Kepotret Owner Visual UAT Route Catalog

Source of truth: `docs/references/architecture/Kepotret_Frontend_Final_Traceability.md`. This catalog preserves the implementation routes and labels shared and state-driven surfaces rather than adding routes. The URL examples use only synthetic stable IDs from `tests/uat/constants.ts`. API-backed views use the Playwright route fixtures; static pages do not.

Review priority is the proposed wave order, not product severity. Wave 7 covers cross-cutting Assistant, modal, empty, error, and responsive states (C01-C09). Use PowerShell `pnpm uat:visual` to open desktop review, or `pnpm uat:visual:mobile` for Pixel 7 emulation. The runner starts at the public landing page and remains paused for manual route switching.
